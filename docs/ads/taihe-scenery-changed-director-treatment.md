# 太和工房 ×「風景換了，它沒換」— 導演拍攝設定書

版本 v1 · 2026-09-05
產品：TR55 運動水壺 / ST-CBH-F60 保溫瓶
規格：30s 主片（16:9）、15s、6s bumper、9:16 社群版

---

## 0. 一句話

女主角走過一天的六個地方、六種光、六種心情。畫面上所有東西都在換：地點、天氣、衣服、表情。唯一不動的，是她右手裡那支壺，永遠站在畫面同一個位置。最後一顆鏡頭，手放開了，壺還在，字落在她的臉原本待的地方。

---

## 1. 核心創意怎麼翻成鏡頭語言

概念是「變 vs 不變」。所以整支片的影像規則只做一件事：**把「不變」做成可以量測、可以重現的固定值，然後把其他所有變數開到最大。**

### 三個鎖死的不變

1. **壺位不變（C-frame）**：每個場景都有一顆「定位鏡頭」，壺在畫面同一個座標、同樣大小、同樣朝向。這是全片的骨架，剪接靠它做 match cut。
2. **壺光不變**：外面是清晨藍還是霓虹紫都無所謂，壺本身的亮度與顏色用一顆小 LED 補到每場一致。不然剪在一起壺會忽亮忽暗，「沒換」就破功。
3. **動作不變**：開蓋 → 喝兩口 → 停一下 → 蓋回（喀）。這個儀式每場都出現，只有速度跟著心情變。最後一場她不喝，只是放下。

### 全部放大的會變

地點、時間、天氣、色溫、服裝、髮型、表情、環境音、她的姿態、運鏡的性格。

### 為什麼這樣做

觀眾不是讀到 tagline 才懂概念。他們是在第 16–19 秒那段連續快切裡，「看見」壺沒動、背景在跳，身體先懂了。最後的字只是確認。

### 兩支產品怎麼處理

「它沒換」的「它」必須是單一個物件。一支片裡中途換產品，概念會被自己拆掉。建議：

- **主版 A：TR55**。偏動態，戶外場多，透明壺身看得到水在晃。
- **主版 B：ST-CBH-F60**。偏靜態，冷天、夜雨、室內。開蓋有蒸氣是它的紅利。
- **同一份分鏡、同一批場景**。每個 setup 拍完 A 壺，馬上換 B 壺再拍一次。拍攝時間多約 25%，製作費省一半。
- **品牌版（選用）**：結尾桌上兩支並排，字改成「風景換了，太和工房沒換」。

## 2. C-frame 規格（全片最重要的一頁）

| 項目 | 設定 | 為什麼 |
|---|---|---|
| 鏡頭 | 50mm（全幅等效；APS-C 機用 35mm） | 透視接近肉眼，背景不變形，六場接起來空間感一致 |
| 光圈 | **f/2.8**，不要 f/1.4 | 背景必須看得出「是哪裡」。景太糊，「風景換了」就沒東西可換 |
| 幀率 / 快門 | 24fps、1/48 | 全片運動模糊一致 |
| ISO / ND | 原生 ISO，白天上可變 ND（6–9 格） | 白天要壓到 f/2.8 1/48 一定要 ND |
| 色彩 | Log 10-bit，白平衡每場手動固定、記下 K 值 | 場景色溫要「故意不一樣」，但壺要在後期可以拉回一致 |
| 機高 | 壺的高度（約她胸口），水平，不俯不仰 | 壺是主角，機器就放在主角的視線高度 |
| 機距 | **1.2m**，每場用捲尺量 | 壺在畫面裡的大小才會一樣 |
| 構圖 | 壺直立在**右側三分線**上，瓶蓋頂貼上三分線；她的臉在**左側三分線**；背景約佔畫面 60% | 臉負責「情緒變」，背景負責「風景變」，壺負責「不變」，三件事各佔一區不打架 |
| 壺朝向 | Logo 正對鏡頭。壺背面貼一小塊膠帶當握位記號，她的拇指每次都壓在膠帶上 | 六場 Logo 角度一致，快切才無縫 |
| 握法 | 右手，四指扣壺、拇指在前，手肘微彎，壺離身體一個拳頭 | 手的形狀也是「不變」的一部分 |
| 運鏡 | 全部同一種：**極慢推進**，10 秒推 8–10% 畫幅。滑軌或雲台皆可，速度一致 | 連續剪接時動量會接起來，看起來像一顆鏡頭沒停過。靜態鏡頭反而會讓每次切都「頓」一下 |
| 監看 | 第一場拍好後截圖畫線，之後每場在監視器疊這張透明線稿對位 | 現場對，不要賭後期 |
| 直式版 | 另拍一組 9:16 的 C-frame，壺放畫面中央偏右（x≈0.6） | 橫式裁直式會把壺切掉或臉切掉，構圖就是這支片的概念，不能裁 |

## 3. 場景、光線走向與情緒弧線

六場走「一天的光」：藍 → 灰白 → 綠 → 金 → 霓虹 → 鎢絲。但六套服裝都不同、髮型也換，觀眾會自己讀出：這不是一天，是很多天。

|---|---|---|---|---|---|---|

## 6. 剪接、轉場、聲音

### 剪接原則

- **蒙太奇段全部硬切**，不用溶接。溶接會把「跳」變成「滑」，概念就軟掉。
- 快切連環段：後期先追蹤壺、把壺釘在畫面同一個像素位置（允許 1–2% 縮放與位移補正），再切。現場對線是為了讓後期只需微調，不是取代。
- 4W 是全片唯一的慢動作。不要到處放慢，慢一次才有價值。
- 6C 是全片唯一完全靜止的鏡頭。前面每一顆都要有運動（哪怕是極慢推），這樣靜止才有重量。

### 轉場手法（給剪接的選項）

1. **壺位 match cut**：主武器。壺不動、背景換。
2. **甩鏡**：從 A 場的壺甩出、甩進 B 場的壺，方向與速度一致。備用於 W→W 之間。
3. **遮擋切**：路人、公車、浪頭掃過畫面時切。用在 1W→2W。
4. **聲音先行（J-cut）**：下一場環境音提前 4–6 格進來。每次換景都用，觀眾的耳朵會先到達。
5. **「喀」定拍**：瓶蓋聲永遠落正拍，它是剪接的節拍器。

### 聲音設計

- 環境音每場「故意不一樣」：鳥、車內廣播、風、浪、雨、房間音。這是聲音版的「風景換了」。
- 音樂：一個鋼琴或吉他 motif，**從頭到尾不變調、不換旋律**，只有編曲厚度隨場景增減。這是聲音版的「它沒換」。夜雨段抽到只剩 motif；家的那場音樂停。
- 三個 foley 要乾淨收：開蓋、吞水、蓋回的喀。
- 不要旁白。字幕只在最後出現一次。若品牌堅持要旁白，只放一句在 6C 字出現時：「還在。」

### 字卡與結尾

- 「風景換了，它沒換。」落在 6C 左側三分線，就是她的臉整支片待的位置。細黑體或明體，暖白，1s 淡入，停 1.5s。
- End card：太和工房 Logo、產品名（TR55 / ST-CBH-F60），pack shot 底。

## 8. 表演與造型

### 表演總則

- 不演情緒，做「可以做的事」。上面每場都給了一句指令，那是給她的，不是給觀眾的。
- 儀式動作固定：開蓋 → 兩口 → 停 → 蓋回。速度隨心情：河濱急、公車機械、山暢快、海慢、雨不喝、家放下。
- 永遠右手、拇指壓膠帶記號、Logo 朝鏡頭。這是她這兩天唯一要背的東西。
- 不看鏡頭。全片沒有一次眼神接觸。

### 造型

- 六套服裝、六種髮型狀態（濕、綁、放、帽子、風吹亂、家居）。服裝色不要跟壺同色，也不要純白，讓壺在每場都是畫面裡最穩的那塊顏色。
- 妝淡，第 5 場允許一點狼狽。
- 壺的顏色：TR55 選一支中明度高飽和的色，才能同時站在白天空、綠山、霓虹前。確認素材裡實際有的顏色再定。F60 不鏽鋼要控反射，現場用黑旗與角度處理。
